# Retail Sales Analysis Project 📊

An end-to-end data analysis project on online retail sales, designed to extract actionable business insights using **SQL, Pandas, SQLite, and data visualization techniques**.

This project explores **sales performance, customer purchasing behavior, product trends, and geographic revenue distribution** to support better business decision-making.

---

## 🎯 Project Objectives

The main goals of this project are to:

- Analyze sales performance over time
- Identify seasonal revenue trends
- Discover top-performing products
- Measure customer behavior using metrics like **Average Order Value (AOV)**
- Understand geographic revenue distribution
- Build a modular and reproducible analysis workflow using **SQL and Python**

---

## 🛠 Tech Stack

- **Language:** Python
- **Database:** SQLite
- **Data Manipulation:** Pandas
- **Visualization:** Matplotlib
- **Analysis:** SQL  
  *(SQL queries are stored separately for modularity and easier maintenance.)*
